# Volthera: The Dominion
Unity-based strategy game developed for the *Modern szoftverfejlesztési eszközök* course (GKNB_INTM006 / GKNB_INTM129) at Széchenyi István University.

## Features
- 4×4 grid-based board
- Turn-based multiplayer gameplay
- Special tiles per species
- JSON save/load system
- Visual feedback
- Basic Unity Play Mode testing
- NUnit unit tests

## Getting Started
1. Open project in Unity 2022.3+
2. Open `Main.unity` scene
3. Press Play
